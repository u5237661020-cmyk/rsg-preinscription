Migration des données Firebase → base o2switch

Cette page copie toutes les données de l'ancienne base Firebase (préinscriptions, dossiers supprimés, tarifs et réglages, base licenciés Footclubs, configuration globale) vers la nouvelle base MySQL o2switch.

À faire une seule fois, depuis un ordinateur. La copie peut être relancée sans risque : les dossiers déjà copiés sont simplement remplacés par leur version Firebase. Firebase n'est pas modifié.
